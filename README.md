# Subtitle Synchronizer

Приложение за Android TV (тествано за X96 M200, Android TV 14), което показва субтитри от `.srt`
файл **над картината на друг плейър** (ViMu Media Player) и позволява да ги синхронизирате
**с дистанционното, докато филмът върви**. ViMu не се променя по никакъв начин: той продължава
да пуска суровия звук (SPDIF/bitstream) към ресивъра, а това приложение се грижи само за субтитрите.

## Как работи

- Работи като услуга за достъпност. Само така може да рисува над друго приложение и да получава
  бутоните на дистанционното, докато ViMu е отпред.
- Позицията на филма се взема от ViMu през Android MediaSession (нужен е „Достъп до известия“).
  Пауза, връщане и превъртане във ViMu се следват автоматично.
- Ако плейърът не съобщава позицията си, се ползва **ръчен часовник**: синхронизира се с
  „синхрон по реплика“ и следи бутоните Play/Pause.
- Всичко се помни поотделно за всеки `.srt` файл.

## Инсталиране

1. Изтеглете готовия файл от папка [`apk/`](apk/) – отворете `SubtitleSynchronizer-1.0.apk`
   и натиснете бутона **Download** (иконата със стрелка надолу, горе вдясно). Инсталирайте го на приставката.
2. Отворете **Subtitle Synchronizer** и дайте трите разрешения от екрана с настройки.
3. Android 13+ блокира „Достъпност“ за ръчно инсталирани приложения. Ако не може да се включи,
   изпълнете от компютъра (с включено мрежово отстраняване на грешки на приставката):

```bash
adb connect IP_НА_ПРИСТАВКАТА:5555
adb shell appops set com.senseart.subsync ACCESS_RESTRICTED_SETTINGS allow
adb shell appops set com.senseart.subsync MANAGE_EXTERNAL_STORAGE allow
adb shell cmd notification allow_listener com.senseart.subsync/com.senseart.subsync.MediaListenerService
adb shell settings put secure enabled_accessibility_services com.senseart.subsync/com.senseart.subsync.SubSyncService
adb shell settings put secure accessibility_enabled 1
```

> `settings put secure enabled_accessibility_services` замества списъка с включени услуги за
> достъпност. Ако ползвате и други такива, добавете ги, разделени с `:`.

4. В приложението натиснете **„Задай бутон“** и натиснете бутон от дистанционното, който не ползвате
   във ViMu (цветен бутон, „Меню“, цифра…). С него се отваря панелът.
5. Във ViMu **изключете неговите субтитри**, за да не се виждат двойно.

## Управление по време на филма

| Бутон | Действие |
|---|---|
| бутонът за панела | отваря панела за синхрон; още веднъж – менюто |
| ◀ / ▶ | субтитрите по-рано / по-късно с 0.1 с; при задържане 1 с, после 10 с на стъпка |
| OK | запомня момента, за синхрон по реплика |
| ▲ / ▼ | избор на реплика от списъка |
| OK (втори път) | „тази реплика започна в запомнения момент“, отместването се изчислява само |
| BACK | затваря панела |

**Синхрон по реплика:** щом чуете реплика, натиснете OK. После с ▲▼ намерете тази реплика в
списъка и натиснете OK. Ако по-късно във филма разликата пак се появи (субтитри за друга честота
на кадрите), повторете синхрона. С две точки се изчислява и **скоростта**.

**Менюто** съдържа: фина скорост (±0.05%), готови настройки 25 ↔ 23.976 fps, нулиране, запис на
синхрона в самия `.srt` (оригиналът остава като `.srt.bak`), избор на друг файл, скриване на
субтитрите, размер и височина на текста, източник на времето, пауза и корекция на позицията.

## Компилиране

```bash
./gradlew testDebugUnitTest assembleRelease
```

APK файлът е в `app/build/outputs/apk/release/app-release.apk`. Подписва се с ключа от `keystore/`,
за да може новите версии да се инсталират върху старите.
